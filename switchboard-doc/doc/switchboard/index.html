Switchboard🔗ℹ

TuringLambdaAI

Public module: switchboard

Switchboard is a uniform client for hosted LLM APIs: one chat surface, one tool-calling surface, one embedding surface, one exception hierarchy — every model addressed as a "provider/model" string. OpenAI-compatible endpoints (OpenAI, Gemini, Mistral, DeepSeek, Ollama, anything else registered) share one code path; Anthropic gets a native adapter for its Messages API.

Switchboard is not an agent framework, a prompt library, or a vector store. It owns exactly the boundary between Racket code and model APIs, and it performs no hidden work: no retries, no hidden default provider, no implicit model.
